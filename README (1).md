# 🛡️ TrustLens Arc — Hackathon Prototype

**Tagline:** Don't just detect the scam. Prove the evidence and verify in 1-click.

## 🚀 Overview
TrustLens Arc is a cybersecurity and safety-tech web companion designed to protect students from fake internship offers, scholarship scams, and fraudulent job postings.

## 🌟 Key Features
1. **Multi-Format Input:** Paste message text, URLs, or upload offer letter screenshots/PDFs.
2. **Explainable Risk Map:** Breaks down trust factors into Verified Evidence, Unverified Details, and Critical Red Flags.
3. **Cross-Source Consistency Engine:** Side-by-side verification table comparing offer claims with real-world DNS/corporate records.
4. **1-Click HR Verification Assistant:** Automatically generates a formal email draft addressed to the official corporate HR desk.
5. **Community Scam Pattern Radar:** Anonymized feed tracking active student scam campaigns.

## 🛠️ How to Run
Simply open `index.html` in any web browser! No backend installation needed for this client-side prototype.
