# 🛡️ TrustLens Arc — Technology Stack & Dependencies

## 🎨 Frontend & UI
* **Framework:** HTML5 / JavaScript (ES6+)
* **Styling:** Tailwind CSS (CDN)
* **Icon Library:** Lucide Icons (`lucide-react`)

## 📑 Document & OCR Engines
* **Image OCR:** Tesseract.js (Client-side text extraction)
* **PDF Parser:** PDF.js / PyPDF2

## 🔍 Verification & Security Infrastructure
* **Domain Check:** WHOIS API & DNS Records
* **Analysis Model:** Google Gemini API (Structured JSON risk breakdown)
